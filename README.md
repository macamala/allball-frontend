# NinkoSports official News data snapshots

This data-only branch holds timestamped, validated public football records for News. It contains no application code, credentials, raw source pages or AI-written articles.

The News refresh workflow on master updates only allowlisted datasets after source identity, season, structure and robots-policy checks. A failed source retains its prior successful timestamp. Consumers must enforce staleness limits; these are not Live Scores feeds.
